# 題庫格式（乙級職安術科練習 APP）

題庫檔是一個 JSON 陣列，每個元素是一個「題組」。

```jsonc
{
  "id": "S-A-01",                 // 唯一代號：S=自編、O=官方舊題；第二段=出題群組；第三段=流水號
  "source": "self",               // "self" 自編 | "official-old" 官方舊制試題
  "category": 1,                  // 1 職業安全衛生相關法規 | 2 職業安全衛生計畫及管理 | 3 專業課程
  "topic": "職業安全衛生管理辦法｜管理單位及人員",  // 章節分類，給 APP 篩選用
  "title": "事業單位安全衛生組織",   // 題組標題（短）
  "context": "某事業單位……",       // 選填：題組共用情境敘述
  "items": [ /* 子題，至少 2 題，題組內子題 points 合計 = 10 */ ]
}
```

## 子題共用欄位

```jsonc
{
  "id": "S-A-01-1",
  "type": "truefalse | single | multi | matching | fill | ordering | linking | calc",
  "points": 2.5,                  // 題組內合計 10 分
  "stem": "題幹",
  "explanation": "解析：說明正確答案為何正確、錯誤選項錯在哪，全部要能由 citations 推得",
  "citations": [
    { "pcode": "N0060027", "article": "6", "quote": "條文中逐字的一段摘錄（可只截一段，空白不計）" }
  ]
}
```

- `article`：條號字串，例如 "6"、"29-1"；附表用 "附表二"。
- `quote`：必須是該條條文的**連續原文**（比對時忽略空白與換行）。長度 8 字以上，不要整條貼上，挑能直接支撐答案的那段。
- 計算題的公式必須引用到出處條文。

## 各題型的作答欄位

### truefalse 是非題
```jsonc
{ "type": "truefalse", "answer": true }
```

### single 單選題
```jsonc
{ "type": "single", "options": [{"id":"A","text":"…"},{"id":"B","text":"…"},{"id":"C","text":"…"},{"id":"D","text":"…"}], "answer": "C" }
```

### multi 複選題（至少 2 個正確答案）
```jsonc
{ "type": "multi", "options": [ …4–6 個… ], "answer": ["A","C","D"] }
```

### matching 配合題（選項可重複使用，拖曳到空格）
```jsonc
{
  "type": "matching",
  "options": [{"id":"A","text":"每月"},{"id":"B","text":"每年"},{"id":"C","text":"每三年"}],
  "blanks": [{"id":"1","label":"一般安全衛生教育訓練…"},{"id":"2","label":"…"}],
  "answer": {"1":"B","2":"A"}
}
```

### fill 填空題（數字鍵盤輸入數值）
題幹用 `{{1}}`、`{{2}}` 標出空格位置。
```jsonc
{
  "type": "fill",
  "stem": "雇主對於高度在 {{1}} 公尺以上之工作場所邊緣……",
  "blanks": [{"id":"1","unit":"公尺"}],
  "answer": {"1": 2}
}
```

### ordering 排序題（全對才給分）
只有在條文明確給出順序，或依條文數值大小排序時才出這題型。
```jsonc
{ "type": "ordering", "options": [{"id":"A","text":"…"},…], "answer": ["C","A","B","D"], "orderHint": "由小到大" }
```

### linking 連連看（左邊每列連到每一欄各 1 個答案）
```jsonc
{
  "type": "linking",
  "left": [{"id":"1","text":"有機溶劑作業"},{"id":"2","text":"缺氧危險作業"}],
  "columns": [
    {"title":"適用法規", "options":[{"id":"a","text":"有機溶劑中毒預防規則"},{"id":"b","text":"缺氧症預防規則"}]}
  ],
  "answer": {"1":["a"],"2":["b"]}
}
```
`answer` 每個 left id 對應一個陣列，依欄位順序各給一個 option id。

### calc 計算題
```jsonc
{
  "type": "calc",
  "answer": 85.3,
  "unit": "分貝",
  "tolerance": 0.1,               // 允許的絕對誤差
  "decimals": 1,                  // 題目要求的小數位數（題幹要寫清楚「四捨五入至小數點後第 1 位」）
  "steps": ["步驟 1：…", "步驟 2：…"]   // 完整計算過程，每步都要能由引用公式推得
}
```
計算題可以在一題內問多個數值：改用 `fill` 題型加上 `steps` 欄位。

## 鐵則（違反就刪題）
1. 題目、答案、錯誤選項、解析中的每一個事實，都只能來自 `corpus/text/` 裡的條文，不能用自己的記憶補。
2. 標記 `[尚未施行-禁止出題]` 的條文不能引用；`[附表尚未施行]` 的條文不能考附表數值。
3. 條文只寫「依附表」但附表內容不在文字裡的，不能考附表內容。
4. 錯誤選項必須明確和條文矛盾（例如數字改掉、主體換掉），不能是「條文沒提到所以可能也對」的模糊選項。
5. 計算題的數字一定要用 Python 實際算過。
6. 不要抄任何補習班、書籍、網站的題目文字。題目全部自己依條文撰寫。
