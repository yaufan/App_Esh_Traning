## 各題型的答案格式（和題庫一致）
- truefalse：`true` 或 `false`
- single：選項 id 字串，例如 `"C"`
- multi：選項 id 陣列（所有正確選項），例如 `["A","C"]`
- matching：`{"空格id": "選項id", ...}`（選項可重複使用）
- fill：`{"空格id": 數值, ...}`
- ordering：選項 id 依正確順序排列的陣列
- linking：`{"左欄id": ["第1欄選項id", "第2欄選項id", ...], ...}`（每欄各一個）
- calc：數值

## 輸出
寫成 JSON 陣列，每個子題一筆，不可遺漏：
```json
[
  {"itemId": "S-A-01-1", "answer": <依上面格式>, "basis": "依據的條文與一句話理由（例如：職安法第 2 條第 2 款）", "doubt": ""},
  {"itemId": "S-A-01-2", "answer": "B", "basis": "…", "doubt": "選項 A 依第 X 條但書也可能成立，因為…"}
]
```
`doubt` 沒有疑問就留空字串。有下列情形一定要寫：答案不唯一、題幹缺少必要條件、選項文字與條文有出入但無法判定對錯、在條文中找不到依據、題幹或選項的事實敘述與條文矛盾（即使不影響答案）。
