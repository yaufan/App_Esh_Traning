# 官方舊題解答任務說明（共用）

背景：職業安全衛生管理乙級 105–109 年的術科是紙筆問答，官方試卷題目已抽成 `/home/claude/work/old/official_questions.json`（只有官方題目文字，沒有任何解答）。你要依**現行法規**為這些題目撰寫參考答案，放進練習 APP 的「官方舊題」區。委託人要求：**不能有幻覺，每個答案都要有法規依據。**

## 資料
- 題庫格式：`/home/claude/work/SCHEMA.md`（先完整讀過；本任務主要用 `essay` 題型，見下方）
- 法規依據庫（唯一事實來源，2026-11-07 版）：`/home/claude/work/corpus/text/`
- 驗證程式：`python3 /home/claude/work/scripts/validate.py <你的檔案>`
- **不要上網，不要參考任何補習班、書籍、網站的解答。** 你沒看過任何解答，只依條文作答。

## 輸出格式
每一題官方試題 = 一個題組：
```jsonc
{
  "id": "O-109-3-01",               // O-{梯次}-{兩位數題號}
  "source": "official-old",
  "session": "109-3", "no": 1,
  "category": 1,                     // 依內容判斷：1 法規定義與一般規定；2 管理辦法、教育訓練、承攬、自動檢查等管理面；3 設施、營造、衛生、計算等專業面
  "topic": "職業安全衛生法｜用詞定義",  // 主要依據法規｜主題
  "title": "職業安全衛生法之場所與工作者",  // 簡短標題
  "originalText": "官方題目原文（照抄 official_questions.json 的 text）",
  "hasFigure": false, "figureNote": "",   // 照抄
  "items": [ /* 每個小題一個子題 */ ]
}
```
子題（每個小題一個，`stem` 用小題原文；沒有小題就用整題）：
```jsonc
{
  "id": "O-109-3-01-1",
  "type": "essay",
  "points": 4,                         // 官方配分；題組內合計 10（官方原本就是每題 10 分）
  "stem": "(一)職業安全衛生法所稱之場所除工作場所外，尚包括那 2 種？(4 分)",
  "modelAnswer": ["1. 勞動場所……", "2. 作業場所……"],   // 參考答案要點，一點一行；題目要求列舉 N 項而條文列更多時，全部列出並在第一行註明「條文共列 X 項，任答 N 項」
  "explanation": "說明答案出自哪條哪款，以及作答重點",
  "citations": [ { "pcode": "...", "article": "...", "quote": "逐字摘錄" } ],
  "lawChangeNote": "（選填）若現行條文與出題年度的規定不同（例如條號、用語、數值已修正），在這裡說明：本答案依現行第 X 條；題目中的某某說法為舊法。無法確定舊法內容時不要猜，只寫「本答案依民國 115 年現行條文撰寫」即可。"
}
```
- 小題是**單純數值填空**（題目用 (1)(2) 標空格、答案都是數字）時，可改用 `fill` 題型：`stem` 用 `{{1}}` 取代空格，`answer` 給數值，並附 `blanks` 的單位。答案不是數字的空格維持 `essay`。
- 小題是**計算題**時用 `calc` 題型，`steps` 寫完整算式；公式必須出自所引條文。
- 純數學、與法規無關的計算（例如兩層濾材的總過濾效率）可以收錄：用 `calc`，`citations` 留空陣列，並填 `basisNote`：「本題為計算原理題，非法規條文；依……原理計算」，steps 要完整，答案用 Python 算過。

## 收錄判斷（很重要）
以下情況**不收錄**這題，改寫進排除清單：
- 答案需要依據庫以外的資料：例如 CNS 國家標準內容、勞工保險職業病種類表、健康職場認證方案、職業災害統計的失能判定規則細節、工程設計公式（氣罩排氣量、風扇定律等）、技術指引、教科書概念（4E、骨牌理論等）。
- 依據的法規條文已刪除、或現行版本在依據庫中標 `[尚未施行-禁止出題]` 而無法確定目前適用內容。
- 題目附圖且圖的內容是作答必要資訊，而 figureNote 無法還原。
- 一題中只有部分小題無法作答時：能作答的小題照常收錄，無法作答的小題不收，但題組內配分要依官方配分保留（`points` 照官方），讓總分可以小於 10；在題組加欄位 `"omittedParts": ["(二)"]` 說明省略哪些小題及原因。（validate.py 會要求合計 10 分：遇到這種題組請把該題組加上 `"partial": true`，驗證程式會放寬。）

排除清單寫到：`/home/claude/work/old/excluded_{你的批次}.json`，格式 `[{"session":"109-3","no":10,"reason":"..."}]`。

## 品質要求
- 參考答案要像好的講義：要點清楚、用語貼近條文，但每一點都要有引用支撐。
- 題目若問「依某某法規定」而現行該條已修正，以現行條文作答，並在 `lawChangeNote` 說明。
- 不確定的寧可不收。
