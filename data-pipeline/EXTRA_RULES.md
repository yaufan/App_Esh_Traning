# 審題後確立的補充規則（出題時一律遵守，違反會被刪題）

1. **排序題**：先後順序必須是條文「明文」列出的步驟順序，或條文中明確數值的大小；由條文間接推論的順序不可出題。
2. **概括條款不當答案**：「其他有關…事項」「其他經中央主管機關指定…」這類概括條款，不可當成正確選項、得分要點或配合題的答案。
3. **題組標題與 topic 不可洩題**：標題只寫主題，不可出現答案中的數值、期限或結論。
4. **不寫條文以外的說法**：解析、題幹、選項都不可出現「常考」「陷阱」「實務上」「一般而言」「考試重點」等經驗或背景敘述；只能寫條文推得出的內容。
5. **錯誤選項**：必須和條文明確矛盾（改數值、改頻率、換主體、把「應」改「得」等）。若一個「錯誤」敘述在別條條文其實成立，就不能用。出題前要檢查同法其他條文與但書。
6. **限定詞要寫足**：條文有適用條件（事業類別、人數門檻、設備種類、但書）時，題幹要把條件寫清楚，使答案唯一。
7. **不重複既有題目**：開始前先讀 `/home/claude/work/bank/` 中同類別既有題組（見任務指定的檔案），不可再出同一條文同一考點的題；同一部法規可以出，但要換條文或換考點。
8. **無單位的數值**：填空或計算題答案沒有單位時，`unit` 用空字串 `""`。
9. **題型要多樣**：整份檔案 8 種題型（truefalse、single、multi、matching、fill、ordering、linking、calc）中至少用到 6 種；計算題只在條文有公式或數值可算時才出。
10. **id 規則**：題組 id 為 `S-<群組字母>-<兩位流水號>`，子題 id 為題組 id 加 `-1`、`-2`…。
11. 引用時 `pcode` 取自依據庫檔名開頭（例如 `N0060001`），`article` 用條號字串。標 `[尚未施行-禁止出題]` 的條文不可用。
